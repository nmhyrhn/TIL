# 문서 목적

MVP 화면 목록과 화면별 표시 정보·입력 항목·버튼·이동 흐름을 정리한다.

관련 업무 정책: 취미 장비 대여 플랫폼 — 1개월 MVP 기획

# 화면 정의 기준

각 화면은 다음 항목을 함께 확정한다.

- 화면 목적
- 접근 가능한 사용자
- 표시 정보
- 입력 항목
- 버튼 및 사용자 행동
- 상태별 노출 차이
- 다음 화면 이동
- 예외 메시지

# 화면별 정의

## 1. 회원가입

### 화면 목적

신규 사용자가 계정을 생성한다.

### 접근 사용자

비로그인 사용자

### 입력 항목

- 이메일: 필수, 이메일 형식, 중복 불가
- 닉네임: 필수, 2~12자, 중복 불가
- 연락처: 필수, 010-0000-0000 형식
- 비밀번호: 필수, 8~20자, 영문과 숫자 포함
- 비밀번호 확인: 필수, 비밀번호와 일치
- 서비스 이용약관 동의: 필수
- 개인정보 수집·이용 동의: 필수

### 사용자 행동

- 이메일과 닉네임 입력을 마치면 서버에서 중복 여부를 확인한다.
- 별도의 중복 확인 버튼은 제공하지 않는다.
- 회원가입 제출 시 서버에서 형식과 중복 여부를 다시 검증한다.
- **회원가입** 버튼을 누르면 계정을 생성한다.
- **이미 계정이 있나요? 로그인** 링크를 누르면 로그인 화면으로 이동한다.

### 성공 처리

회원가입 성공 후 로그인 화면으로 이동한다.

### 오류 메시지

- 이미 가입된 이메일입니다.
- 이미 사용 중인 닉네임입니다.
- 올바른 연락처를 입력해주세요.
- 비밀번호는 영문과 숫자를 포함한 8자 이상이어야 합니다.
- 비밀번호가 일치하지 않습니다.
- 필수 약관에 동의해주세요.

## 2. 로그인

### 화면 목적

기존 사용자가 이메일과 비밀번호로 로그인한다.

### 접근 사용자

비로그인 사용자

### 입력 항목

- 이메일: 필수, 이메일 형식
- 비밀번호: 필수

### 사용자 행동

- **로그인** 버튼을 누르면 인증을 요청한다.
- **회원가입** 링크를 누르면 회원가입 화면으로 이동한다.
- 로그인 유지 체크박스와 비밀번호 찾기는 제공하지 않는다.

### 성공 처리

로그인 성공 후 장비 목록 화면으로 이동한다. 로그인 상태는 인증 만료 시각까지 유지한다.

### 오류 메시지

보안을 위해 이메일과 비밀번호 중 어떤 값이 틀렸는지 구분하지 않는다.

- 이메일 또는 비밀번호가 올바르지 않습니다.

## 3. 장비 목록

### 화면 목적

등록된 대여 가능 장비를 검색·필터·정렬해 조회한다.

### 접근 사용자

로그인 여부와 관계없이 접근할 수 있다. 예약과 장비 등록은 로그인 후 가능하다.

### 상단 메뉴

비로그인 사용자:

- 로고
- 장비 등록
- 로그인
- 회원가입

로그인 사용자:

- 로고
- 장비 등록
- 마이페이지
- 로그아웃

비로그인 사용자가 장비 등록을 누르면 로그인 화면으로 이동한다.

### 검색·필터·정렬

- 검색어: 장비명과 제조사에 통합 적용
- 카테고리: 전체 또는 하나 선택
- 정렬: 최신 등록순·낮은 대여료순·높은 대여료순
- 기본 정렬: 최신 등록순
- 검색어·카테고리·정렬 조건은 함께 적용한다.

### 장비 카드 표시 정보

- 대표 사진
- 카테고리
- 장비명
- 제조사
- 교환 역
- 일일 대여료
- 보증금

카드를 누르면 장비 상세 화면으로 이동한다. 제공자 닉네임은 카드에 표시하지 않는다.

### 목록 처리

- 한 페이지당 12개
- 페이지 번호 방식
- 대여 중지 장비는 제외
- 예약 중인 장비도 목록에는 표시

### 결과 없음

**조건에 맞는 장비가 없습니다.** 메시지와 필터 초기화 버튼을 표시한다.

## 4. 장비 상세 및 예약 신청

### 화면 목적

장비 상세 정보와 예약 가능 날짜를 확인하고 예약을 신청한다.

### 접근 사용자

로그인 여부와 관계없이 접근할 수 있다. 예약 신청은 로그인 사용자만 가능하다.

### 표시 정보

- 대표 사진
- 장비명
- 카테고리
- 제조사: 값이 없으면 항목은 유지하고 값을 비워 표시
- 구성품 및 상태
- 제공자 닉네임
- 교환 역
- 일일 대여료
- 보증금
- 예약 불가능 날짜

연락처와 이메일은 표시하지 않는다.

### 예약 입력

- 대여 시작일: 필수
- 대여 종료일: 필수
- 희망 수령 시간: 필수, 00:00~23:30의 30분 단위
- 희망 반납 시간: 필수, 00:00~23:30의 30분 단위
- 비고: 선택, 최대 200자

예약 대기·예약 확정·수령 확인 요청·대여 중·반납 중인 날짜는 달력에서 선택할 수 없다.

### 금액 표시

시작일과 종료일을 선택하면 다음 금액을 자동 계산한다.

- 일일 대여료 × 대여 일수
- 보증금
- 결제 금액

**현장에서 거래 당사자가 직접 정산합니다.** 안내 문구를 표시한다.

### 사용자별 버튼

비로그인 사용자:

- 예약 신청을 누르면 로그인 화면으로 이동한다.

다른 사용자의 장비를 보는 로그인 사용자:

- 필수 입력을 완료하면 예약 신청 버튼을 활성화한다.

본인 장비를 보는 사용자:

- 예약 입력 영역을 숨긴다.
- 수정과 대여 중지 버튼을 표시한다.

### 예약 신청 처리

1. 서버에서 기간 중복과 장비 상태를 다시 검사한다.
2. 성공하면 예약 대기를 생성한다.
3. 예약 상세 화면으로 이동한다.

### 오류 메시지

동시에 다른 사용자의 예약이 먼저 생성된 경우:

- 선택한 기간은 방금 예약되었습니다. 다른 날짜를 선택해주세요.

대여 중지된 장비인 경우:

- 현재 대여할 수 없는 장비입니다.

## 5. 장비 등록

### 화면 목적

회원이 대여할 장비와 거래 조건을 등록한다.

### 접근 사용자

로그인 사용자

### 입력 항목

- 장비명: 필수, 최대 50자
- 카테고리: 필수, 드롭다운
- 제조사: 선택, 자유 입력, 최대 30자
- 구성품 및 상태: 필수, 최대 300자
- 교환 역: 필수, 역명 검색 후 하나 선택
- 일일 대여료: 필수, 1원 이상 정수
- 보증금: 필수, 0원 이상 정수
- 대표 사진: 필수, JPG·PNG, 최대 5MB

### 교환 역 선택

- 사용자가 입력한 역명으로 검색한다.
- 검색 결과에는 역명과 노선명을 표시한다.
- 지역명은 검색 조건과 화면 표시에 사용하지 않는다.
- 사용자는 검색 결과에서 하나의 역을 선택한다.

### 화면 기능

- 사진 선택 후 미리보기를 표시한다.
- 금액 입력 시 천 단위 쉼표를 표시한다.
- 필수값을 모두 입력해야 등록 버튼을 활성화한다.
- 제조사가 비어 있어도 등록할 수 있다.
- 상세 화면에는 제조사 항목을 유지하고 값만 비워 표시한다.
- 임시저장 기능은 제공하지 않는다.

### 버튼 및 이동

- 등록: 장비 생성 후 해당 장비 상세 화면으로 이동
- 취소: 장비 목록 화면으로 이동

### 오류 메시지

- 지원하지 않는 이미지 형식입니다.
- 이미지는 5MB 이하만 등록할 수 있습니다.
- 필수 정보를 입력해주세요.
- 올바른 금액을 입력해주세요.

## 6. 장비 수정·관리

### 화면 목적

본인이 등록한 장비를 조회하고 수정·대여 중지·재개·삭제한다.

### 접근 사용자

해당 장비를 등록한 로그인 사용자

### 내 장비 목록

- 대표 사진
- 장비명
- 카테고리
- 교환 역
- 일일 대여료
- 상태: 대여 가능·대여 중지
- 수정 버튼

장비를 선택하면 수정 화면으로 이동한다.

### 예약 이력이 없는 장비

다음 항목을 모두 수정할 수 있다.

- 장비명
- 카테고리
- 제조사
- 구성품 및 상태
- 교환 역
- 일일 대여료
- 보증금
- 대표 사진

삭제와 대여 중지도 가능하다.

### 예약 이력이 있는 장비

변경 불가:

- 장비명
- 카테고리
- 제조사

변경 가능:

- 구성품 및 상태
- 교환 역
- 일일 대여료
- 보증금
- 대표 사진

변경 내용은 새로 생성되는 예약에만 적용하며 기존 예약 스냅샷은 유지한다. 삭제할 수 없고 대여 중지만 가능하다.

### 버튼 및 이동

- 저장: 변경 내용을 저장하고 장비 상세 화면으로 이동
- 대여 중지: 목록과 검색 결과에서 장비를 숨기고 신규 예약을 차단
- 대여 재개: 장비를 목록과 검색 결과에 다시 노출
- 삭제: 예약 이력이 없을 때만 표시
- 취소: 저장하지 않고 이전 화면으로 이동

### 상태 처리

- 대여 중지해도 기존 예약은 유지한다.
- 삭제 전 확인 창을 표시한다.
- 본인이 등록하지 않은 장비의 수정 URL로 접근하면 권한 오류를 표시한다.

## 7. 마이페이지

### 화면 목적

회원정보와 장비·예약 관련 주요 메뉴를 한곳에서 제공한다.

### 접근 사용자

로그인 사용자

### 회원정보 표시

- 닉네임
- 이메일
- 연락처

### 회원정보 수정

- 닉네임: 수정 가능, 중복 검사
- 연락처: 수정 가능
- 이메일: 읽기 전용
- 회원정보 수정 버튼
- 비밀번호 변경 버튼

비밀번호 변경 시 현재 비밀번호와 새 비밀번호를 입력한다.

### 주요 메뉴

- 내 장비 관리: 등록한 전체 장비 수 표시
- 내가 빌린 예약: 처리 필요 건수 강조
- 내 장비에 들어온 예약: 처리 필요 건수 강조

각 메뉴를 누르면 해당 목록 화면으로 이동한다.

### 제외

- 통계 차트
- 거래 금액 합계
- 후기·평점
- 회원 탈퇴
- 별도 알림함

### 접근 사용자

로그인 사용자

- 처리 필요
- 진행 중
- 종료

### 예약 카드 표시 정보

- 예약 상태
- 처리 필요 배지
- 예약 당시 대표 사진
- 장비명
- 제공자 닉네임
- 교환 역

### 화면 목적

본인이 제공자로 참여한 예약을 상태별로 조회한다.

로그인 사용자

- 전체
- 처리 필요
- 진행 중
- 종료

- 예약 상태
- 처리 필요 배지
- 예약 당시 대표 사진
- 장비명
- 대여자 닉네임

- 대여 시작일·종료일

- 결제 금액
- 예약 대기 상태의 승인 가능 남은 시간

카드를 누르면 예약 상세 화면으로 이동한다. 승인·거절과 상태 변경 버튼은 목록에 표시하지 않는다.

### 목록 처리

### 결과 없음

**해당 상태의 예약이 없습니다.** 메시지를 표시한다.

## 10. 예약 상세

### 화면 목적

예약 당시 정보와 현재 상태를 확인하고, 거래 역할과 상태에 따라 필요한 행동을 수행한다.

### 접근 사용자

해당 예약의 대여자 또는 장비 제공자

### 공통 표시 정보

- 현재 예약 상태
- 예약 신청 시각
- 예약 당시 대표 사진
- 장비명
- 제조사
- 구성품 및 상태
- 제공자 닉네임
- 대여자 닉네임
- 교환 역
- 수령·반납 날짜와 시간
- 비고
- 일일 대여료
- 대여 일수
- 보증금
- 결제 금액
- 거절·취소 사유

예약 확정 이후에는 거래 상대의 연락처를 표시한다. 이메일은 표시하지 않는다.

### 상태별 표시와 버튼

#### 예약 대기

공통:

- 승인 가능 남은 시간 표시

대여자:

- 예약 취소

제공자:

- 예약 승인
- 예약 거절

#### 예약 확정

대여자:

- 예약 취소

제공자:

- 수령 확인 요청
- 예약 취소

#### 수령 확인 요청

대여자:

- 장비 수령 확인

제공자:

- 상태만 확인

#### 대여 중

대여자:

- 반납 중 처리

제공자:

- 상태만 확인

#### 반납 중

대여자:

- 상태만 확인

제공자:

- 거래 완료

#### 종료 상태

거래 완료·예약 취소·예약 거절·예약 만료·제공자 취소 상태에서는 변경 버튼을 표시하지 않는다.

### 확인 창

상태를 변경하기 전에 작업에 맞는 확인 창을 표시한다.

- 이 예약을 승인할까요?
- 장비를 수령한 것이 맞나요?
- 장비를 반납 중으로 변경할까요?
- 장비 반납을 확인하고 거래를 완료할까요?

거절과 취소 시 확인 창에서 사유를 선택한다.

### 예외 처리

- 예약 대기 만료 후 승인 시도: 승인 가능 시간이 만료된 예약입니다.
- 본인이 참여하지 않은 예약 접근: 이 예약을 조회할 권한이 없습니다.
- 이미 변경된 상태의 버튼을 다시 실행: 현재 예약 상태에서는 처리할 수 없습니다.
