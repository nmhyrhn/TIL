## 팀프로젝트

영수증 OCR 기능이 단순 분석에서 실제 냉장고 등록 기능으로 이어지게 되었다.

이전까지는 영수증 이미지를 읽는 것까지만 가능했다면, 이제는 다음 흐름이 가능하다.

영수증 이미지
→ OCR 분석
→ 사전 재료 매칭
→ 후보 확인
→ 후보 수정/제외
→ 냉장고 등록
처음부터 OCR 결과를 바로 냉장고에 넣지 않고 후보 검토 단계를 둔 점이 중요했다.
OCR은 항상 정확하지 않을 수 있기 때문에, 사용자가 확인하고 승인하는 구조가 더 안전하다.

또한 냉장고 등록은 기존 FridgeItemService를 재사용해 기존 정책을 유지했다.
새 기능이 기존 기능을 우회하지 않도록 만든 점이 이번 작업의 핵심이었다.

다음 작업에서는 TossPayments 결제와 구독, 정산 흐름으로 넘어갈 예정이다.
