# REFramework 정리

- REFramework는 반복 업무와 예외 처리를 안정적으로 관리하는 표준 템플릿입니다.
- 전체 구조는 State Machine입니다.
- 주요 State는 Init, Get Transaction Data, Process Transaction, End Process입니다.
- 한 번에 처리하는 데이터 한 건을 Transaction이라고 합니다.
- Orchestrator 없이 사용할 때는 TransactionItem을 DataRow 형식으로 변경합니다.
- Business Exception은 현재 데이터만 넘기고, System Exception은 환경을 재초기화한 뒤 재시도합니다.
- 실제 업무 로직은 주로 Process.xaml에 작성합니다.
