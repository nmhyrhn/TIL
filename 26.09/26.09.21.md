# REFramework는 왜 사용할까?
예를 들어 Excel에 거래처 100개가 있고, 거래처마다 홈택스에서 사업자 상태를 조회한다고 가정해 보겠습니다.
일반 Sequence만 사용하면 중간의 53번째 거래처에서 브라우저 오류가 발생했을 때 다음과 같은 문제가 생길 수 있습니다.
- 프로세스 전체가 중단됨
- 어느 거래처까지 처리했는지 파악하기 어려움
- 처음부터 다시 실행할 수 있음
- 오류 로그와 재시도 처리를 직접 만들어야 함
# REFramework는 이러한 상황을 대비한 기본 구조를 제공합니다.
- 데이터를 한 건씩 구분하여 처리
- 정상·업무 오류·시스템 오류 구분
- 시스템 오류 발생 시 재시도
- 각 단계의 실행 로그 기록
- 브라우저와 프로그램의 초기화 및 종료 관리
- 처리할 데이터가 없어지면 정상 종료

즉, REFramework의 핵심은 다음과 같습니다.
많은 데이터를 한 건씩 안정적으로 처리하고, 오류가 발생해도 전체 프로세스를 관리할 수 있게 만드는 구조
