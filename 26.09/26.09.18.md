# REFramework
## Robotic Enterprise Framework (REFramework)는 UiPath 에서 제공하는 고급 템플릿

- Initialization (Init) <br>
프로세스 초기화를 위한 작업을 수행합니다. 이는 애플리케이션의 시작, 데이터 로드 등을
포함합니다.
- Get Transaction Data  <br>
처리할 데이터(트랜잭션)를 가져온 다음, 데이터의 적합성을 확인합니다.
 <br>트랜잭션 처리시 Queue/Non-Queue 방식 선택가능

- Process Transaction 가져온 데이터를 처리합니다.
- End Process 프로세스를 종료하고, 필요한 경우 정리 작업을 수행합니다.
