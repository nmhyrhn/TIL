# 과제 진행

Get Transaction Data <br>
 └─ dtAllProducts에서 이번 제품 한 행을 가져옴<br>
                  ↓<br>
Process Transaction<br>
 └─ Process.xaml 호출<br>
     │<br>
     ├─ ① ExtractProductDetails.xaml<br>
     │    제품 URL로 이동<br>
     │    심의사항의 마지막 조회 내역 열기<br>
     │    상세 정보 수집<br>
     │<br>
     ├─ ② DownloadEvidenceFiles.xaml<br>
     │    이번 제품의 파일 경로 초기화<br>
     │    첨부파일이 없으면 건너뛰기<br>
     │    있으면 모든 파일 다운로드 반복<br>
     │    저장한 파일 경로 반환<br>
     │<br>
     ├─ ③ 상세 정보 + 파일 경로를 결과 한 행에 누적<br>
     │<br>
     └─ ④ 상세 창 닫기·목록 복귀<br>
                  ↓<br>
Get Transaction Data에서 다음 제품 가져오기
