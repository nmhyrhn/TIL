# 핵심 용어 정리 

- Transaction: 반복 처리할 업무 한 건
- TransactionItem: 현재 처리 중인 한 건
- TransactionNumber: 현재 처리 순서
- Init: 설정을 읽고 프로그램을 실행하는 단계
- Get Transaction Data: 다음 처리 대상을 가져오는 단계
- Process Transaction: 실제 업무를 처리하는 단계
- End Process: 프로그램과 리소스를 정리하는 단계
- BusinessRuleException: 데이터·업무 규칙 문제
- System.Exception: 프로그램·네트워크·화면 문제
- Config: 경로, URL, 재시도 횟수 등의 설정
- Asset: Orchestrator에 저장한 공용 설정
- Credential: 안전하게 보관된 아이디·비밀번호
- Queue: 처리할 업무 목록
- Queue Item: Queue에 들어 있는 업무 한 건
- Dispatcher: Queue에 업무를 넣는 프로세스
- Performer: Queue의 업무를 처리하는 프로세스
