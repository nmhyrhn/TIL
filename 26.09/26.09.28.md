# 개인 과제 진행

Get Transaction Data 진행 기록
- Init에서 수집한 전체 제품 목록을 Main의 dt_TransactionData로 전달했다.
- GetTransactionData.xaml은 이 목록을 io_dt_TransactionData 인수로 받는다.
- in_TransactionNumber에 해당하는 한 행을 꺼내 out_TransactionItem으로 반환한다.
- Main은 반환된 행을 TransactionItem에 받고, Process로 전달한다.
- 처리할 행이 더 없으면 Nothing을 반환해 종료 단계로 이동하도록 구성했다.
- 실행 확인: 거래 번호가 1 → 2 → 3으로 증가하는 것을 확인하고 중단했다. 전체 목록 처리 후 종료는 아직 확인하지 않았다.
- Process가 비어 있어 현재의 Transaction Successful은 실제 정보 수집 완료를 의미하지 않는다.
