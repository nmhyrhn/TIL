# REFramework란 무엇인가
REFramework는 Robotic Enterprise Framework의 약자입니다.
반복 처리 업무를 안정적으로 운영하기 위해 UiPath가 제공하는 State Machine 기반 프로젝트 템플릿입니다. 
로깅, 초기화, 예외 처리, 재시도 같은 운영 기능이 기본 구조에 포함되어 있습니다. 
UiPath 공식 REFramework 설명
핵심 흐름은 다음과 같습니다.

## 각 상태가 하는 일

### Init
- Config 파일 읽기
- Orchestrator Asset·Credential 읽기
- 애플리케이션 실행
- 로그인
- 초기 데이터 준비
### Get Transaction Data
- 처리할 다음 업무 한 건을 가져오기
- 예: Queue Item, Excel 한 행, 이메일 한 건
- 더 이상 데이터가 없으면 종료
### Process Transaction
- 실제 업무 한 건 처리
- ERP 입력, 파일 생성, 이메일 발송 등
- 처리 결과 저장
### End Process
- 프로그램과 브라우저 종료
- 최종 로그 또는 결과 보고
- 리소스 정리

## 반드시 구분해야 할 두 예외
### BusinessRuleException
- 데이터나 업무 규칙이 잘못된 경우
- 예: 계좌번호 누락, 승인 한도 초과, 잘못된 주문번호
- 다시 실행해도 대개 해결되지 않음
- 해당 건만 실패 처리하고 다음 건으로 이동
### System.Exception
- 프로그램이나 실행 환경 문제
- 예: ERP 응답 없음, selector 불일치, 네트워크 오류
- 재시도하면 성공할 가능성이 있음
- 애플리케이션을 복구하거나 재시작한 뒤 재시도
면접에서는 이 두 예외의 차이와 재시도 정책을 자주 확인합니다.
