# TIL - 프로젝트 발표 PPT 작성

프로젝트 발표를 위한 PPT 제작 작업을 진행했다.  
기능 구현과 QA가 어느 정도 정리된 상태에서, 프로젝트 내용을 발표 흐름에 맞게 재구성하는 데 집중했다.

## 진행 내용

- 프로젝트 소개 흐름 정리
- 주요 기능과 사용자 흐름 정리
- 냉장고, 장보기, 레시피 등 핵심 기능 화면 구성
- ERD, API, QA 결과 등 기술 자료 반영 방향 정리
- 발표용 문구와 화면 배치 조정
- Canva를 활용한 발표 자료 제작

## 정리한 부분

PPT는 단순히 작업 내용을 나열하는 문서가 아니라, 프로젝트를 처음 보는 사람도 흐름을 이해할 수 있게 구성해야 한다.

그래서 다음 순서가 자연스럽도록 정리했다.

1. 프로젝트 주제와 문제 정의
2. 주요 기능 소개
3. 사용자 흐름
4. 구현 화면
5. DB 및 API 구조
6. QA와 개선 사항
7. 결과 및 회고

특히 냉파마스터는 냉장고 재료 관리, 장보기, 레시피 추천 흐름이 서로 연결되는 서비스이기 때문에 각 기능을 따로 설명하기보다 “사용자가 재료를 관리하고 활용하는 흐름” 중심으로 보여주는 것이 중요했다.

## 느낀 점

구현할 때는 기능 단위로 생각했지만, 발표 자료를 만들면서 프로젝트를 보는 관점이 달라졌다.  
코드나 API 기준이 아니라 사용자가 어떤 문제를 겪고, 이 서비스가 그 문제를 어떻게 해결하는지 중심으로 정리해야 전달력이 좋아진다는 점을 느꼈다.

또한 PPT 작업을 하면서 문서화와 발표 준비도 프로젝트의 일부라는 점을 다시 확인했다.  
기능이 잘 구현되어 있어도 그것을 명확하게 설명하지 못하면 프로젝트의 완성도가 잘 전달되지 않는다.

## 핵심 정리

프로젝트 발표 PPT를 만들며 기능 구현 내용을 사용자 흐름과 발표 구조에 맞게 정리했다.  
이번 작업을 통해 구현 결과를 설명 가능한 형태로 재구성하는 과정도 개발 프로젝트 마무리에서 중요한 단계라는 점을 정리할 수 있었다.
