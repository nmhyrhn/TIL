# TIL - 차주 QA 및 문서 최신화 계획 회의

이번 회의에서는 차주에 진행할 QA와 문서 최신화 작업 범위를 정리했다.  
기능 구현이 어느 정도 진행된 만큼, 앞으로는 구현된 내용을 기준으로 문서와 실제 동작 흐름을 맞추는 작업이 중요해졌다.

## 진행 내용

- 유스케이스 최신화
- ERD 명세서, DDL 최신화
- 불필요한 데이터 정리
- Git 이슈 기반 통합 QA 항목 도출
- 개발계획서 최종 정리
- 발표용 PPT 계획 및 초안 작성 논의

## 문서 최신화

기존에 작성한 유스케이스와 ERD, DDL이 실제 구현 내용과 달라질 수 있기 때문에 최신 상태로 맞추는 작업이 필요하다고 정리했다.

특히 ERD와 DDL은 DB 구조와 직접 연결되므로, 사용하지 않는 데이터나 변경된 컬럼이 남아 있으면 이후 QA나 발표 준비 과정에서 혼란이 생길 수 있다.  
따라서 현재 구현 기준으로 필요한 데이터만 남기고, 명세와 실제 구조가 일치하는지 확인하기로 했다.

## 통합 QA 준비

Git 이슈를 기준으로 기능별 작업 내역을 다시 확인하고, 이를 바탕으로 통합 QA 항목을 뽑기로 했다.

단순히 기능이 구현되었는지만 보는 것이 아니라, 사용자 흐름 기준으로 기능이 자연스럽게 이어지는지 확인하는 방향으로 정리했다.

예를 들면 다음과 같은 흐름을 기준으로 볼 수 있다.

- 회원가입 및 로그인
- 냉장고 재료 등록, 수정, 삭제
- 장보기 항목 추가, 체크, 냉장고 반영
- 사전 재료 관리자 기능
- 권한별 접근 가능 여부

## 개발계획서와 발표 준비

개발계획서는 최종 구현 내용과 현재 프로젝트 방향에 맞춰 정리해야 한다.  
또한 발표용 PPT는 단순 기능 나열보다는 프로젝트 목적, 주요 기능 흐름, DB 구조, 구현 결과, QA 계획이 자연스럽게 이어지도록 구성하는 방향을 논의했다.

## 정리

이번 회의는 추가 기능 구현보다 프로젝트 마무리를 위한 정리 작업에 가까웠다.  
구현된 기능을 기준으로 문서, DB 명세, QA 항목, 발표 자료를 최신화하면서 프로젝트의 완성도를 높이는 단계로 넘어가고 있음을 확인했다.
