# TIL - 발표 PPT 완성 및 시연 영상 제작

프로젝트 발표를 위한 PPT를 완성하고, 실제 서비스 흐름을 보여줄 시연 영상 제작 작업을 진행했다.  
구현된 기능을 단순히 설명하는 것에서 끝내지 않고, 사용자가 어떤 흐름으로 서비스를 사용하는지 발표 자료와 영상에 담는 데 집중했다.

## 진행 내용

- 발표용 PPT 최종 정리
- 프로젝트 소개, 주요 기능, 기술 구조, QA 내용 정리
- 화면 캡처 및 발표 흐름에 맞춘 슬라이드 구성
- 서비스 시연 영상 제작
- 시연 순서와 사용자 흐름 점검
- 발표 자료와 시연 영상의 내용 연결 확인

## PPT 완성

PPT는 프로젝트를 처음 보는 사람도 흐름을 이해할 수 있도록 구성했다.

특히 냉파마스터의 핵심 기능인 냉장고 재료 관리, 장보기, 레시피 추천 흐름이 자연스럽게 이어지도록 정리했다.  
기능을 각각 따로 나열하기보다, 사용자가 재료를 등록하고 관리한 뒤 장보기와 레시피 기능으로 확장하는 흐름을 중심으로 보여주도록 구성했다.

또한 ERD, API, QA 결과, 개선 사항 등 개발 과정에서 정리한 자료들도 발표 흐름에 맞게 반영했다.

## 시연 영상 제작

시연 영상은 실제 사용자가 서비스를 사용하는 순서대로 구성했다.

예를 들면 다음과 같은 흐름을 확인하며 제작했다.

- 로그인 및 서비스 진입
- 냉장고 재료 등록
- 재료 목록 확인
- 장보기 항목 추가
- 장보기 항목 체크 및 냉장고 반영
- 레시피 관련 기능 확인
- 관리자 기능 또는 주요 보완 기능 확인

시연 영상은 말로 설명하기 어려운 사용자 흐름을 한 번에 보여줄 수 있기 때문에, 발표에서 프로젝트 완성도를 전달하는 데 중요한 자료가 된다.

## 느낀 점

발표 준비를 하면서 구현한 기능을 다시 사용자 관점에서 바라보게 되었다.  
개발할 때는 API, DB, 컴포넌트 단위로 기능을 나눠서 보지만, 발표에서는 사용자가 어떤 문제를 해결하는지와 기능들이 어떻게 연결되는지가 더 중요했다.

또한 시연 영상을 만들면서 실제 서비스 흐름이 끊기지 않는지 다시 점검할 수 있었다.  
발표 자료와 시연 영상은 단순 산출물이 아니라, 프로젝트를 최종적으로 검증하고 설명 가능한 형태로 정리하는 과정이라는 점을 정리할 수 있었다.

## 핵심 정리

프로젝트 발표 PPT를 완성하고 시연 영상을 제작하면서, 구현 결과를 발표 가능한 형태로 정리했다.  
이번 작업을 통해 기능 구현, 문서화, QA, 발표 자료가 모두 프로젝트 완성도를 보여주는 요소라는 점을 다시 확인했다.
